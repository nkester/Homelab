# Purpose: Architectural Decision Records (The "Why") - System History

This is the Black Box Recorder. ADR stands for Architectural Decision Record. It captures the "Why" behind a specific change, specifically focusing on the trade-offs made at a point in time.

Content: Short, immutable documents that follow a specific pattern (Context, Decision, Consequences).

Scope: Historical records of pivot points.
